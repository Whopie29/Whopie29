<h3 align="center">🏙️ 3D Contribution Skyline</h3>

<p align="center">
<img src="https://raw.githubusercontent.com/Whopie29/Whopie29/main/profile-3d-contrib/profile-night-rainbow.svg"/>
</p>

<details>
<summary><b>⚙️ One-time setup (~2 min) — self-hosted, won't break</b></summary>
<br>

This renders your contribution graph as an animated, rotating 3D skyline. It's generated by a GitHub Action that commits the image straight into this repo — no dependency on a third-party server, so it can't get "paused" like the old stats/trophy widgets did.

1. In this repo (`Whopie29/Whopie29`), go to **Actions → New workflow → set up a workflow yourself**.
2. Name the file `profile3d.yml` and paste in:

```yaml
name: 3D Contribution Graph
on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch: {}

permissions:
  contents: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: yoshi389111/github-profile-3d-contrib@0.7.1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          USERNAME: ${{ github.repository_owner }}

      - name: Commit generated graph
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git pull --rebase
          git add profile-3d-contrib
          git diff --staged --quiet || git commit -m "chore: update 3d contribution graph"
          git push
```

3. Commit it, then run it once manually from the **Actions** tab (`Run workflow`).
4. It creates a `profile-3d-contrib/` folder with several themed SVGs (`profile-night-rainbow.svg`, `profile-south.svg`, etc.) — the graph above loads automatically once that folder exists. Swap the filename in the `<img>` tag above if you prefer a different theme/angle; the action's repo has a preview of all of them.

</details>
